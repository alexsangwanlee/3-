          업비트 → 마이페이지 → Open API 관리에서 발급합니다. 자산조회·주문조회·주문하기만 켜고 출금은 끄세요. 이 PC의 공인 IP를 등록해야 합니다. 저장한 키는 화면에 다시 보여주지 않습니다.

          알림 (선택)

          텔레그램 @BotFather로 봇을 만들어 토큰을 받고, 그 봇에게 말을 건 뒤 chat id를 확인하세요. 매수·매도·손절과 주간 점검이 옵니다.

          AI 주간 검토 (선택, Claude 또는 GPT)

          둘 중 하나의 API 키만 넣으면 됩니다 (Claude: console.anthropic.com, GPT: platform.openai.com). 둘 다 넣으면 Claude를 씁니다. 매주 재검증이 끝나면 AI가 장부·거래·실제 비용을 읽고 한국어로 검토해 텔레그램과 이 화면에 알려줍니다. AI는 주문을 내지 않고 키도 보지 못합니다. 검토 한 번에 API 사용료가 조금 듭니다.
